# 仮仕様の一覧（要確認）

設計書で「未確定」「案」とされていた点は、実装上いったん次のように決めています。
多くは管理メニュー（管理者ツール → 各種設定）で変えられます。確定したら、この表を更新してください。

## ダンジョン

| 項目 | 仮の決定 |
|---|---|
| 挑戦の形 | 1 階の受付で開始する階を選び、2→9 階を、建物両端の階段を交互に歩いて上っていく（部内で決定） |
| 開始できる階 | 最初は 2 階のみ。突破した階の次の階からも始められる（部内で決定） |
| 各階の進行 | 中ボスの壁をクリック → 中ボス闘技場 → 元の場所へ戻り壁が消える → 出口の階段の壁をクリック → ボス闘技場 → 元の場所へ戻り階段が現れる → 歩いて次の階へ（部内で決定） |
| 中ボスの壁 | フロアを東西に分ける壁の出入口（泣く黒曜石） |
| ボスの壁 | 出口側の上り階段の最初の 3 段（強化深層岩）。中ボスを倒すまでは開かない |
| 階の敵 | 全滅させなくてもボスの壁は調べられる（倒すとポイント） |
| 闘技場 | 各階に中ボス用（25×25）とボス用（33×33）。上空 y 200 に並べる。階のテーマに合わせた素材 |
| 全滅 | 挑戦中のメンバー全員が倒れている状態になったら、その回は終了して 1 階へ。解放と報酬は残る（部内で決定）。1 人で挑戦中は死んだ時点で終了 |
| 同時挑戦 | 1 フロア（とその階の闘技場）につき 1 パーティー。次の階が使用中なら、ボス闘技場で空くまで待つ |
| パーティーの条件 | 全員が開始する階を解放済みであること |
| パーティー人数 | 最大 4 人（`cfg party_max`） |
| 出現数 | 通常 4+階、強化 階-1、エリート 階÷3（`/ufd count`） |
| 内装 | 2〜9 階を自動生成（tools/dungeon）。開始部屋（敵なし）は階段の横。エレベーター側はふさいだ |
| 貢献の判定 | その敵にダメージを与えた人だけが討伐報酬を受け取る。クリア報酬はセッション中に 1 回以上ダメージを与えた人 |
| 再突破報酬 | 初回突破報酬の 20％（`cfg repeat_rate`） |
| 制限時間 | 1 つの階につき 20 分（`cfg session_minutes`）。全員が 30 秒以上不在なら終了 |
| 初回報酬の物資 | 2 階: 回復キット 3 個＋パン 8 個、4 階: 武器強化素材 3 個、9 階: 完成記念品「15号館 制覇の証」（名前と日付入り）＋最終強化パーツ（全員に告知）。全階でその階の武器（`uf_19_gear.sk`）。他の階の「素材」はショップの解放で代用 |
| 宝箱のレアリティ | 階が 1 上がるごとに ノーマル -3％、レア +1％、エピック +1.5％、レジェンダリー +0.5％（`cfg chest::shift`） |
| レジェンダリーの中身 | 守護のお守り・武器パーツ・その階の武器（3 分の 1 ずつ） |
| 敵のドロップ | ダメージを与えた人それぞれに直接渡す（地面に落とさない）。強化素材: 通常 4％・強化 8％・エリート 15％・中ボス 1 個・ボス 2 個。レアドロップ品（その階）: 強化 2％・エリート 8％・中ボス 25％・ボス 50％。特殊素材: エリート 3％・中ボス 10％・ボス 20％。武器パーツ: ボス 10％。手下からは落ちない（`drop::<tier>::<素材>`） |
| レアドロップ品 | 2 先生の赤ペン・3 古文書のページ・4 光る試薬・5 壊れた基板・6 警備員の鍵束・7 教授の研究ノート・8 錆びた封鎖の鍵・9 15号館の主のかけら |
| 特殊能力 | 階ごとに武器と防具の能力が 1 つずつ（武器: 疾風・ふきとばし・毒・雷・足止め・会心・吸収・業火 / 防具: 俊足・鉄壁・解毒・反撃・再生・幸運・回避・剛力）。その階の武器ははじめからその階の能力を持つ。鍛冶屋で特殊素材 1 ＋ レアドロップ品 1 で 1 つ付ける（付け直すと前のは消える） |
| 鍛冶屋 | `/upgrade` か鍛冶屋の NPC。強化（Lv0→5 強化素材、Lv5→10 最終強化パーツ）、特殊能力、武器パーツ 3 → 最終強化パーツ 1 |

## 死亡・回収・蘇生

| 項目 | 仮の決定 |
|---|---|
| ポイントを失う範囲 | ダンジョンのワールドのみ（`cfg death_loss_scope dungeon/all/none`） |
| 複数回死亡 | 死亡地点ごとに別々に保存し、件数の上限なし。期限なし |
| 回収方法 | 本人が死亡地点から 2.5 ブロック以内に入る。48 ブロック以内に近づくと、死亡地点に本人にだけ見える光の柱（回収マーカー）が出る。座標はチャットと `/points` でも案内 |
| 蘇生 | 死亡した人は復帰地点で復活し、仲間が死亡地点で 5 秒しゃがむと呼び戻される。受付は 60 秒（`cfg soul_seconds`） |
| 蘇生の中断 | 蘇生している人がダメージを受けると、進行が 0 に戻る |

## RPG

| 項目 | 仮の決定 |
|---|---|
| レベル上限 | 50 |
| 必要経験値 | 100 + 50 ×（レベル − 1） |
| 経験値の入手 | 討伐（報酬ポイントの半分）、クリア（階 × 20）、クエスト |
| スキル | 体力強化 / 攻撃強化 / 守り / 採集の達人、各 5 段階、1 段階につき 1 ポイント |
| 振り直し | 500pt でスキルポイントを全額返す |
| 武器強化 | Lv0→5 は強化素材 1 個ずつ、Lv5→10 は最終強化パーツ 1 個。1 レベルにつき +10％。強化すると耐久値も回復する |
