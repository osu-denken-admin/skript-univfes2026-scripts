# テスト計画

自動で試せる部分は `tests/bot`（ボットによるプレイテスト）でも確認できます。手順は [tests/bot/README.md](../tests/bot/README.md)。

すべてテスト環境（本番とは別のサーバー、または本番のコピー）で行います。
各項目を実施したら、結果と日付を記録してください。**ログでエラーが出ていないこと**と、**ゲーム内の動作**の両方を確認します。

## 0. 読み込み

- [ ] `/sk reload all` でエラーが 0 件（エラーがある場合はファイル名と行番号を記録して修正）
- [ ] 画面下にポイントが出る（`main.sk`。ボスと戦っている間はボスの体力のバー）
- [ ] 全モジュールが無効のまま、プレイヤーから見える変化がない（`/ufadmin module list`）

## 1. 経済・ショップ（economy / shop）

- [ ] `/ufadmin points <自分> give 1000` → `/points` に反映、`univfes_economy.log` に記録
- [ ] `/sell` で小麦などが売れる。特殊アイテム・名前付きアイテムは売れない
- [ ] `/sell list` の名前と実際のアイテムが一致する（一致しなければ `sellprice` で登録し直す）
- [ ] `/buy` で購入できる（QuickShop の `/shop` は今までどおり動く）。ポイント不足・インベントリ満杯・未解放で購入できない
- [ ] GUI からアイテムを取り出せない（シフトクリック、数字キー、ドラッグも試す）
- [ ] 管理メニューで販売停止にすると、ショップから消える
- [ ] 再ログイン・再起動後も残高が残る

## 2. ダンジョン（party / dungeon / death）

- [ ] 2 階の設定 → `/dungeon` → 敵が出る → 全滅で中ボス → ボス → クリア
- [ ] 初回報酬は 1 回だけ。2 回目は再挑戦報酬になる
- [ ] 3 階が解放され、ショップのハンドガンが買えるようになる
- [ ] 攻撃していない人は報酬を受け取れない
- [ ] 宝箱は個人ごとに 1 回だけ開けられる。再接続しても配置は変わらない
- [ ] 時間切れ・全員退出・`/ufd end` で、敵と宝箱が消えてロビーへ戻る
- [ ] 挑戦中にサーバーを再起動しても、敵と宝箱が残らない
- [ ] 死亡でポイントが半分（切り捨て）減り、死亡地点で 1 回だけ回収できる
- [ ] 2 人パーティーで、しゃがみ 5 秒の蘇生ができる。ダメージで中断される

## 3. RPG・道具・武器（rpg / tools / weapons）

- [ ] 討伐で経験値が入り、レベルアップでスキルポイントが入る
- [ ] スキルの習得と振り直し（確認画面あり）
- [ ] 3×3 ピッケルが、サバイバルのワールドでだけ動く。チェスト・保護区域・置いたブロックを壊さない
- [ ] 木こり斧で、自然の木は倒れ、家の柱（葉なし）は 1 ブロックだけ
- [ ] 鉱石探知の表示が、実際の鉱石の方向と合っている
- [ ] グラップリングフックが Java 版・統合版の両方で動く
- [ ] 銃が弾薬を消費して撃てる。プレイヤーには当たらない。ダンジョン外では撃てない
- [ ] **統合版で銃の右クリックが反応するか**

## 4. カジノ（casino）

- [ ] 交換（pt ⇔ チップ）が正しい
- [ ] 最低額・最高額の範囲外では遊べない
- [ ] 管理メニューの理論還元率と、遊んだ回数が増えたときの実際の還元率が近い
- [ ] 設定を変えても、進行中の反応速度ゲームの結果が変わらない

## 5. 管理・運用

- [ ] 管理者が初めて参加すると管理者ツールが配られる。右クリック・左クリック・Q で管理メニューが開く（Java 版は本、統合版はチェスト画面）
- [ ] 本の項目をクリックすると操作され、本が開き直される。マウスを合わせると説明が出る。文字が紙からはみ出さない
- [ ] **統合版**の管理者がタップまたは捨てる操作で管理メニューを開ける
- [ ] 一般プレイヤーは管理者ツールを使えず、拾えない
- [ ] 数値エディタで範囲外の値にならない。「やめる」で変更されない。「決定」で反映され、操作履歴に残る
- [ ] 確認画面の「やめる」で元のページに戻り、何も変わらない
- [ ] 管理メニューの全ページを開いて、エラーが出ない（コンソールを確認）
- [ ] 一般プレイヤーが `/ufadmin` `/ufd` を使えない
- [ ] メンテナンスモードで、一般プレイヤーがキックされ入れない
- [ ] `tools/server/backup.sh` で取ったバックアップを、別のフォルダに展開してサーバーが起動する（**復元テスト**）
- [ ] `mc-server.service` で、プロセスを強制終了すると再起動し、10 分に 5 回より多く落ちると止まる

## 6. 自動反映

仕組み: 10 分ごとに `git pull --ff-only` → HEAD が変わったときだけ `sk reload scripts`（`skript-git-pull.timer`）。

- [ ] サーバーの clone がどのブランチをチェックアウトしているか（`git branch --show-current`）
- [ ] `main` にマージ後、10 分以内に `uf_*.sk` が読み込まれ、エラーが 0 件
- [ ] ダンジョンのクリア直後に `sk reload all` しても、15 秒以内にロビーへ戻りフロアが空く
- [ ] パーティーを組んだまま `sk reload all` しても、パーティーが残る
- [ ] 問題があったときに `git revert` で `main` を戻すと、次の pull で元に戻る
