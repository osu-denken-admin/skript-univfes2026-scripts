# 15号館ダンジョンの内装づくり

15号館 2〜9 階の内装（部屋・通路・家具）を自動で作り、本番へ貼り付けるための道具です。

## できあがっているもの

- `layout/15goukan_dungeon.litematic` … 2〜9 階の内装（8 領域）。Litematica で本番に貼り付ける
- `layout/floor_<階>.json` … 各階の部屋割り・開始地点・ボス・敵の出現地点・宝箱の座標
- `../../uf_15_layout.sk` … 上の座標を、管理者ツールのボタン 1 つで登録するスクリプト（自動生成）

各階のテーマ（2F 教室棟 / 3F 図書室 / 4F 化学実験室 / 5F サーバールーム / 6F 資材倉庫 / 7F 研究室・教授室 / 8F 封鎖区画 / 9F 最上階・大講堂）、平面図は案内図ページを参照。

## 本番への入れ方

1. **バックアップを取る**（ワールドのコピー、または Litematica で 2〜9 階を保存しておく）
2. Litematica の `schematics` フォルダに `15goukan_dungeon.litematic` を入れる
3. ゲーム内で M →「Load Schematics」→ `15goukan_dungeon` を読み込む
4. 「Schematic Placements」→ 読み込んだ配置 →「Configure」で、原点（Origin）を **x = -267, y = 73, z = 87** にする
   - 回転・反転はなし。2 階の床の上に半透明の内装が重なって見えれば位置は正しい
5. OP 権限のあるクリエイティブ状態で、Litematica の貼り付け（Paste Schematic in World）を実行する
6. 管理者ツール →「ワールドとロビー」で 15号館のワールドとロビー（1 階）を登録
7. 管理者ツール →「ダンジョンの各階」→「**15号館の内装に合わせて全階を設定**」→ 確認して実行

## 作り直すとき

```bash
node gen.js <出力フォルダ>                         # 内装を生成（階ごとに seed 固定なので毎回同じ結果）
node preset.js <出力フォルダ> ../../uf_15_layout.sk   # ダンジョン設定スクリプトを作り直す
node tolitematic.js <出力フォルダ> <出力.litematic> <node_modules のパス>
node report.js <出力フォルダ> <出力.html>               # 案内図ページ
```

`tolitematic.js` と `parse.js` は prismarine-nbt を使います（`tests/bot` で `npm install` すると入ります）。

## 確認したこと（2026-10-23、Paper 1.21.4 + Skript 2.16.2）

- 本番から取った 15号館（373,116 ブロック）をテストサーバーに再現し、ボットで全ブロック一致を確認
- 内装を建てた後、ボットで 2〜9 階すべてを開始→中ボス→ボス→クリアまで通しプレイ（ボスはボス部屋に出現）
- `.litematic` を読み戻し、テストサーバー上の内装と 79,872 ブロックすべて一致
- 挑戦中でない人がフロアに入るとロビーに戻されること
