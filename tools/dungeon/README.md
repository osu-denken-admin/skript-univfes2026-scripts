# 15号館ダンジョンの内装と闘技場

15号館 2〜9 階の内装（部屋・通路・家具）と、各階の中ボス・ボス用の闘技場を自動で作り、本番へ貼り付けるための道具です。

## ダンジョンの流れ

1. 1 階の受付で開始する階を選ぶ（最初は 2 階だけ。突破した階の次の階からも始められるようになる）
2. 階の敵を倒しながら進む
3. **中ボスの部屋に入る**と、パーティー全員が上空の **中ボス闘技場** へ移動して中ボス戦。勝つと中ボスの部屋に戻る
4. **階の敵を全滅させる**と、5 秒後に **ボス闘技場** へ移動してボス戦
5. 勝つと突破報酬・次の階の解放。5 秒後に **そのまま次の階** へ（9 階のボスで制覇 → 1 階へ）
6. 全員が倒れる（全滅）・時間切れ・全員不在で、その回は終了して 1 階へ。解放と報酬は残る

1 つの階と、その階の闘技場を同時に使えるのは 1 パーティーだけです。次の階が使用中なら、ボス闘技場で空くまで待ちます。

闘技場は 15号館の北の上空（x -300〜15, z -60〜20, y 200〜209）に並びます。本番でこの範囲に建物がないことを確認してください。

## 本番への入れ方

1. **バックアップを取る**（ワールドのコピー、または Litematica で 2〜9 階と上空の範囲を保存しておく）
2. Litematica の `schematics` フォルダに 2 つの `.litematic` を入れる
3. それぞれ M →「Load Schematics」で読み込み、「Schematic Placements」→「Configure」で原点（Origin）を上の表のとおりに合わせる（回転・反転なし）
   - 内装は、2 階の床の上に半透明の内装が重なって見えれば位置は正しい
4. OP 権限のあるクリエイティブ状態で、Litematica の貼り付け（Paste Schematic in World）を実行する
5. 管理者ツール →「ワールドとロビー」で 15号館のワールドとロビー（1 階）を登録
6. 管理者ツール →「受付・ショップ・カジノの区域」で、1 階の受付の範囲を登録（任意。未設定ならどこからでも挑戦できる）
7. 管理者ツール →「ダンジョンの各階」→「**15号館の内装に合わせて全階を設定**」→ 確認して実行

## 作り直すとき

```bash
node gen.js <出力フォルダ>                          # 内装（階ごとに seed 固定なので毎回同じ結果）
node gen_arena.js <出力フォルダ>                    # 闘技場
node preset.js <出力フォルダ> ../../uf_15_layout.sk # ダンジョン設定スクリプト
node tolitematic.js <出力フォルダ> <出力.litematic> <node_modules のパス> floors
node tolitematic.js <出力フォルダ> <出力.litematic> <node_modules のパス> arenas
node report.js <出力フォルダ> <出力.html>            # 案内図ページ
```

`tolitematic.js` と `parse.js` は prismarine-nbt を使います（`tests/bot` で `npm install` すると入ります）。

## 確認したこと（2026-10-23、Paper 1.21.4 + Skript 2.16.2）

- 本番から取った 15号館（373,116 ブロック）をテストサーバーに再現し、全ブロック一致
- `.litematic` を読み戻し、テストサーバー上の内装と 79,872 ブロックすべて一致
- ボット（`tests/bot/drun.js`）で 2→9 階の通し挑戦: 各階で中ボスの部屋 → 中ボス闘技場 → 戻る → 全滅 → ボス闘技場 → 次の階、9 階後に 1 階へ（72 項目すべて合格）
- 初回は 2 階からのみ、全階突破後は好きな階から始められる。全滅で終了して 1 階で復活する
- 挑戦中でない人がフロアに入るとロビーに戻される
